# Figure Provenance

The conference manuscript uses `fig_domain_profile.pdf`, generated by `corpus/generate_corpus_figures.py`. The manuscript pipeline diagram is drawn directly in the manuscript source and is not part of this companion repository.

The same script also generates companion-level descriptive checks:

- `fig_scope_distribution.pdf`
- `fig_year_distribution.pdf`
- `fig_tpx_profile.pdf`

Legacy figures from the earlier 82-paper extended draft are excluded from this publication release. The current authorities are `corpus/papers.csv`, the generated Core tables, and the PDFs listed above.

Note: `fig_domain_profile.pdf` is the compact layout published as Fig. 3 in the NLPIR 2026 paper (no internal title, sized for a 0.66\textwidth inclusion). `generate_corpus_figures.py` regenerates the same data in the wider companion layout; counts are identical.
